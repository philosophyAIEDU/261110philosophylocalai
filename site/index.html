시험판(v0.2.0)입니다 실제 AI 모델로 하는 검증과 Windows·Mac 실제 컴퓨터에서의 설치 시험이 아직 끝나지 않았습니다. 처음에는 가상 자료로 먼저 사용해 보시고, 실제 학생 개인정보는 충분히 시험한 뒤에 사용해 주세요.

이런 분께 필요합니다

학생 상담 기록, 성적, 대학 내부 문서, 미발표 연구자료를 AI로 정리하고 싶지만 외부 서버로 보내는 것은 걱정되셨던 교수님을 위한 프로그램입니다.

🔒

내 컴퓨터 안에서만 처리

AI가 교수님의 컴퓨터에서 직접 실행됩니다. 문서, 질문, 대화가 인터넷으로 나가지 않습니다. 그리고 “로컬 전용”이라는 표시는 설정값이 아니라 실행 중인 AI를 직접 검사해서 확인된 경우에만 켜집니다.

🖥

컴퓨터에 맞는 AI를 추천

메모리, 그래픽, 저장 공간을 자동으로 확인하고 빠른 AI·균형 잡힌 AI·고성능 AI 중 알맞은 2~3개를 추천합니다.

⬇

버튼 한 번으로 준비

터미널 명령어나 별도 프로그램 설치 없이 AI 실행 엔진과 모델을 자동으로 내려받고, 파일이 올바른지 확인한 뒤 실제로 작동하는지 시험합니다.

🛡

앱 잠금과 보안 점검

잠금 암호·자동 잠금·학생 기록 가명 처리로 개인정보를 한 번 더 보호하고, 보안 점검 화면에서 디스크 암호화까지 확인합니다.

🔄

앱 안에서 업데이트

‘앱 업데이트’ 메뉴에서 새 버전을 확인하고, 공식 파일과 일치하는지 자동으로 검증한 뒤 설치합니다. (v0.2.0부터)

📊

숫자는 정확하게

Excel·CSV의 평균, 합계, 빈 값은 AI가 추측하지 않고 프로그램이 직접 계산합니다. AI는 계산된 표를 해석해 보고서를 씁니다.

할 수 있는 일

결과는 Word(.docx), Excel(.xlsx), 텍스트 파일로 저장할 수 있습니다.

AI와 대화하기

질문, 글 초안, 아이디어 정리. 응답 중지와 복사, 대화 기록 저장 여부 선택.

강의자료 분석

PDF·Word·PowerPoint·텍스트를 요약하고 핵심 개념, 수업 목표, 토론 질문, 퀴즈 초안을 만듭니다. 근거가 된 부분을 함께 보여 줍니다.

학생 지도

상담 기록을 암호화해 보관하고 검색하며, 요약과 지도 계획 초안을 만듭니다.

연구자료 분석

연구자료 요약, 논문 비교, 주제별 정리, 보고서 초안. 없는 참고문헌을 만들어 내지 않도록 설정되어 있습니다.

행정업무 도우미

회의록, 업무보고서, 행사 결과보고서, 공문, 교육 프로그램 운영보고서 초안.

Excel 데이터 분석

기초 통계, 빈 값 확인, 항목별 집계, 그래프, 분석 보고서.

내려받기

컴퓨터에 맞는 파일을 받아 설치하세요. v0.2.2 시험판 · 엔진 재시작·엔진만 설치하는 복구 버튼을 추가했습니다.

앱을 다시 설치해도 AI를 다시 받을 필요가 없습니다앱 전용 모델 폴더에 이미 받은 AI가 있으면 찾아서 재사용합니다. 실행 엔진만 없으면 엔진만 설치합니다. 기존 모델 폴더는 지우지 마세요. v0.2.2에서는 ‘개인정보 보호 설정’ 또는 ‘내 AI 모델 관리’에서 엔진 복구 버튼을 사용할 수 있습니다.

Windows

Windows 10·11 (64비트) · 약 6.9MB · 관리자 권한 필요 없음

⬇ Windows용 내려받기

Mac

macOS 12 이상 · Apple 칩·Intel 공용 · 약 18MB

⬇ Mac용 내려받기

권장 사양: 메모리 8GB 이상, 여유 저장 공간 10GB 이상. 설치 파일은 작지만, 처음 사용하는 컴퓨터에서는 AI 실행 엔진과 AI 모델(수 GB)을 내려받습니다. 이미 받은 모델이 있으면 재사용합니다. 전체 릴리스 정보: GitHub 릴리스 페이지

설치 방법

현재 시험판은 코드 서명이 없어서 처음 설치할 때 경고 창이 나옵니다. 아래 순서대로 진행하시면 됩니다.

Windows에서 설치하기
  1. 내려받은 Philosophy.Local.AI_…_x64-setup.exe를 두 번 누릅니다.
  2. 파란색 “Windows의 PC 보호” 창이 나오면 추가 정보를 누른 뒤 실행을 누릅니다.
  3. 안내에 따라 설치합니다. 교수님 계정에만 설치되며 관리자 권한은 필요하지 않습니다.
  4. 설치가 끝나면 바탕화면 또는 시작 메뉴에서 Philosophy Local AI를 실행합니다.
Mac에서 설치하기
  1. 내려받은 .dmg 파일을 열고, 앱을 응용 프로그램 폴더로 끌어다 놓습니다.
  2. 응용 프로그램에서 앱을 열면 “확인되지 않은 개발자” 경고가 나올 수 있습니다. 일단 닫아 주세요.
  3. 시스템 설정 → 개인정보 보호 및 보안으로 가서 아래쪽의 “그래도 열기”를 누릅니다.
  4. 암호를 입력하면 앱이 열립니다. 이 과정은 처음 한 번만 필요합니다.

처음 실행하면

  1. 컴퓨터 확인메모리와 그래픽을 자동으로 확인합니다. 이 정보는 어디로도 전송되지 않습니다.
  2. AI 고르기주로 하실 일을 고르면 알맞은 AI 2~3개를 추천합니다. 처음에는 “균형 잡힌 추천 AI”를 권합니다.
  3. AI 준비하기이미 받은 AI가 있으면 “이 AI 사용하기”로 바로 시작합니다. 없을 때만 인터넷 사용에 동의하고 내려받습니다. 모델은 있고 실행 엔진만 없으면 엔진만 설치합니다.
  4. 사용 시작준비가 끝나면 AI가 실제로 답하는지 확인한 뒤 바로 사용할 수 있습니다.

개인정보는 이렇게 지켜집니다

보안과 개인정보 보호를 가장 우선해서 만들었습니다.

걱정되는 점이렇게 처리합니다
자료가 외부로 전송될까?AI가 이 컴퓨터(127.0.0.1) 안에서만 실행되며, AI에게 보내는 요청은 이 컴퓨터 밖으로 나가지 않도록 앱이 직접 막습니다. 인터넷은 AI 실행 엔진과 AI 모델을 내려받을 때만, 동의한 경우에만 사용합니다.
클라우드 AI를 쓰지는 않나?AI 엔진의 클라우드 기능을 꺼 두고, 실제로 꺼져 있는지 실행 중에 검사합니다. 클라우드 모델은 선택할 수 없습니다.
저장된 자료는?대화와 상담 기록은 암호화되어 이 컴퓨터에만 저장되고, 암호화 키는 운영체제의 보안 저장소에 보관됩니다. 대화 기록 저장은 기본으로 꺼져 있고, 언제든 완전히 삭제할 수 있습니다.
다른 사람이 내 컴퓨터에서 앱을 열면?앱 잠금 암호를 설정하면 암호 없이는 기록을 열 수 없습니다. 정해진 시간 동안 쓰지 않으면 자동으로 잠기고, 열려 있던 문서도 메모리에서 지웁니다.
화상회의에서 화면을 공유하면?앱 화면은 캡처·공유할 수 있습니다. 화면을 공유하거나 캡처할 때는 상담 기록이 보이는 화면을 닫아 주세요.
AI 결과물에 학생 실명이 남지 않나?학생 기록을 AI에 보내기 전에 이름을 ‘학생1’처럼 가명으로 바꾸고 전화번호·학번 등을 가립니다.
컴퓨터를 반납·폐기할 때는?‘전체 초기화’로 암호화 열쇠를 파기하면, 백업에 남은 이전 사본까지 읽을 수 없게 됩니다.
사용 기록을 수집하나?사용 통계, 오류 보고, 클라우드 백업을 하지 않습니다. 앱이 인터넷을 사용한 내역은 “개인정보 보호 설정”에서 직접 확인할 수 있습니다.

학생 개인정보의 수집·이용·보관은 소속 대학의 개인정보 보호 규정을 따라 주세요.

확인된 것실제 Ollama 엔진으로 공식 파일 무결성, 클라우드 기능 꺼짐, 외부 접속 차단, 종료 시 정리를 확인했고, 인터넷을 끊은 상태에서 앱 기능 테스트를 모두 통과했습니다. (Linux 환경 기준. 자세한 내용은 보안 검증 보고서)

자주 묻는 질문

인터넷이 없어도 쓸 수 있나요?
네. AI 실행 엔진과 AI 모델을 한 번 내려받은 뒤에는 인터넷 없이도 모든 기능을 사용할 수 있습니다.
이 페이지에서 바로 AI를 쓸 수 있나요?
아니요. 이 페이지는 안내와 내려받기를 위한 페이지입니다. 자료를 외부 서버로 보내지 않는 것이 이 프로그램의 핵심이라, 반드시 컴퓨터에 설치해서 사용합니다.
컴퓨터 사양이 낮아도 되나요?
메모리 8GB 이상을 권장합니다. 사양이 낮으면 작고 가벼운 AI를 추천하며, 이 경우 긴 문서 분석 품질은 제한될 수 있습니다. 응답 속도는 컴퓨터 성능에 따라 달라집니다.
어떤 AI 모델을 쓰나요?
공개 모델인 Qwen 3(Apache-2.0)과 Gemma 3(Gemma 이용 약관)를 컴퓨터 사양에 맞춰 추천합니다. 모델 선택과 삭제는 앱의 “내 AI 모델 관리”에서 할 수 있습니다.
Qwen 3Gemma 3AI 실행 엔진: Ollama (MIT)
AI가 만든 결과를 그대로 써도 되나요?
AI가 만든 결과는 초안입니다. AI는 틀릴 수 있으므로 사용하기 전에 내용을 확인해 주세요. 특히 참고문헌, 수치, 인용문은 원문으로 확인하셔야 합니다.
지원하지 않는 파일 형식이 있나요?
PDF, Word(.docx), PowerPoint(.pptx), 텍스트, Excel(.xlsx·.xls), CSV를 지원합니다. 한글(HWP) 파일은 아직 지원하지 않으니 PDF로 저장해서 사용해 주세요. 스캔한 이미지 PDF는 글자를 읽지 못합니다.
제거하려면 어떻게 하나요?
Windows는 설정 → 앱 → 설치된 앱에서, Mac은 응용 프로그램의 앱을 휴지통으로 옮겨 제거합니다. 저장된 자료와 AI 모델까지 지우는 방법은 사용 설명서에 있습니다.
학생 개인정보를 넣어도 되나요?
넣기 전에 앱의 개인정보 보호 설정 → 보안 점검을 모두 초록색으로 만들어 주세요 (잠금 암호, 자동 잠금, 디스크 암호화 등). 그리고 소속 대학의 개인정보 보호 규정을 따라 꼭 필요한 정보만 넣어 주세요. 현재는 시험판이므로 충분히 시험해 보신 뒤 사용하시길 권합니다.
업데이트는 어떻게 하나요?
v0.2.0부터는 앱 왼쪽 메뉴의 앱 업데이트에서 버튼을 누르면 새 버전을 확인하고 설치할 수 있습니다. 버튼을 누를 때만 GitHub에 접속하며, 문서·대화·기록은 전송되지 않습니다.
문제가 생기거나 의견이 있어요
GitHub 이슈에 증상과 운영체제를 알려 주세요. 문서 내용이나 개인정보는 올리지 마세요.
