# 필로소피 로컬 AI v0.2.5 (시험판)

> **AI로 성장하고, 그 성장을 나눈다.**

## 대화와 분석 결과가 이제 기록에 남습니다
지금까지는 AI와 대화하다가 다른 메뉴로 가거나, 강의자료 분석을 하다가 나오면 내용이 모두 사라졌습니다. 이번 버전부터는:

- **메뉴를 옮겨도 그대로**: 작업 중이던 대화, 불러온 파일, 분석 결과, ‘자료에 질문하기’ 내역이 다른 메뉴에 다녀와도 그대로 남습니다.
- **모든 결과를 자동 저장**: AI 대화, 강의자료 분석, 연구자료 분석, 행정업무, 학생 지도, Excel 분석 보고서가 각 메뉴의 **‘지난 기록’**에 자동으로 저장됩니다. 앱을 껐다 켜도 남아 있습니다.
- **다시 보기·내보내기·삭제**: 지난 기록을 눌러 다시 보고, Word·텍스트로 저장하거나 지울 수 있습니다.
- **학생 지도 결과**는 가명 처리된 결과로 저장되고, 가명 대응표는 따로 보관해 Word로 내보낼 때 실명이 섞이지 않습니다.

## 기록은 이렇게 보호됩니다
- 모든 기록은 **암호화되어 이 앱에만** 저장됩니다. 인터넷이나 다른 프로그램으로 나가지 않습니다.
- **앱 잠금 암호**를 설정해 두면 암호 없이는 기록을 열 수 없습니다. 학생 정보를 다룬다면 꼭 설정해 주세요.
- 앱이 잠기면 화면에 열려 있던 내용(대화·결과·불러온 파일)은 메모리에서 지워지고, 저장된 기록은 잠금을 풀면 다시 볼 수 있습니다.
- 기록을 남기고 싶지 않다면 ‘개인정보 보호 설정 → 대화·분석 기록 저장’을 끄면 됩니다. (기본: 켜짐)

## 업데이트 방법
‘앱 업데이트’ 메뉴에서 ‘시험판(베타) 버전도 받기’를 켠 상태로 업데이트를 확인하세요. 기존 기록·설정·잠금 암호·AI 모델은 그대로 남습니다.

코드 서명·공증이 없는 시험판입니다.
