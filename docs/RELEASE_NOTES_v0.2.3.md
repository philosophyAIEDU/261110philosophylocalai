# 필로소피 로컬 AI v0.2.3 (시험판)

## 엔진 다운로드 코드 416 복구
- 이전에 받은 엔진 임시 파일이 완전하면 공식 SHA-256으로 확인하고 다운로드 없이 설치합니다.
- 불완전한 임시 파일의 이어받기 요청이 416으로 거절되면 Range 없이 한 번 다시 요청합니다.
- 처음부터 다시 받은 엔진에도 공식 SHA-256 검증을 적용하며, 일치하지 않으면 설치하지 않습니다.
- 기존 AI 모델과 앱 자료 폴더를 삭제하거나 다시 내려받지 않습니다.
- 정상적인 이어받기와 서버가 Range를 무시하는 경우도 처리합니다.

## 업데이트 후
‘앱 업데이트’에서 ‘시험판(베타) 버전도 받기’를 켜고 v0.2.3으로 업데이트하세요. ‘개인정보 보호 설정’에서 엔진 준비를 다시 실행하면 됩니다. 임시 파일이나 모델 폴더를 직접 지울 필요가 없습니다.

416·206·200 응답을 모사한 HTTP 테스트, 검증된 캐시 재사용, 반복 416 재시도 제한 및 SHA-256 불일치 차단을 확인했습니다. 사용자 컴퓨터에서의 실행 상태는 업데이트 후 별도로 확인해야 합니다.

코드 서명·공증이 없는 시험판입니다.
