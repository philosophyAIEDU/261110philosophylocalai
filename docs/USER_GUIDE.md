# 필로소피 로컬 AI 사용 설명서

> AI로 성장하고, 그 성장을 나눈다.

필로소피 로컬 AI는 교수님의 컴퓨터 **안에서만** 실행되는 AI 프로그램입니다. 학생 정보, 강의자료, 연구자료를 인터넷으로 보내지 않고 분석합니다.

---

## 1. 설치하기

### Windows
1. `Philosophy Local AI_x.y.z_x64-setup.exe` 파일을 내려받아 두 번 누릅니다.
2. **"Windows의 PC 보호"** 파란 창이 나오면 *추가 정보* → *실행*을 누릅니다.
   (현재 버전은 코드 서명이 되어 있지 않아 이 안내가 나옵니다. 소속 기관 IT 부서가 서명된 버전을 배포한 경우에는 나오지 않습니다.)
3. 설치는 **교수님 계정에만** 됩니다. 관리자 권한이 필요하지 않습니다.

### macOS (Apple 칩 및 Intel Mac)
1. `Philosophy Local AI_x.y.z_universal.dmg`를 열고 앱을 **응용 프로그램** 폴더로 끌어 놓습니다.
2. 처음 열 때 **"확인되지 않은 개발자"** 경고가 나오면: *시스템 설정 → 개인정보 보호 및 보안* 아래쪽의 *그래도 열기*를 누릅니다.
   (현재 버전은 Apple 공증을 받지 않았습니다. 공증된 버전에서는 이 단계가 필요 없습니다.)

## 2. 처음 실행 — 4단계
1. **시작하기**: 프로그램 소개를 확인합니다.
2. **컴퓨터 확인**: 메모리, 그래픽, 저장 공간을 자동으로 확인합니다. 이 정보는 어디로도 전송되지 않습니다.
3. **AI 고르기**: 주로 하실 일(두루 사용 / 문서 요약 / 연구자료 / 데이터)을 고르면, 컴퓨터에 맞는 AI 2~3개를 추천합니다.
   - *빠르고 가벼운 AI* · *균형 잡힌 추천 AI* · *고성능 AI*
   - 처음에는 **균형 잡힌 추천 AI**를 권합니다.
4. **AI 내려받기**: "인터넷 사용에 동의합니다"에 표시하고 **이 AI 다운로드하기**를 누릅니다.
   - AI 실행 엔진(처음 한 번)과 AI 모델을 내려받고, 파일이 올바른지 확인하고, AI가 실제로 답하는지 시험합니다.
   - 용량이 커서 수 분~수십 분 걸릴 수 있습니다. 중간에 끊겨도 **다시 시도**를 누르면 이어서 받습니다.

> 인터넷은 **AI 실행 엔진과 AI 모델을 내려받을 때만** 사용합니다. 교수님의 문서, 질문, 대화는 전송되지 않습니다.

## 3. 기능별 사용법

| 메뉴 | 할 수 있는 일 |
|---|---|
| **AI와 대화하기** | 질문, 글 초안, 아이디어 정리. *응답 중지*, *복사* 가능 |
| **강의자료 분석** | PDF·Word·PowerPoint·텍스트를 불러와 요약, 핵심 개념, 수업 목표, 토론 질문, 퀴즈 초안. *자료에 질문하기*는 근거가 된 부분을 함께 보여 줍니다 |
| **학생 지도** | 상담 기록 저장(암호화)·검색, 선택한 기록으로 요약·지도 계획·반복되는 어려움 분석 |
| **연구자료 분석** | 연구자료 요약, 논문 비교, 주제별 정리, 연구 아이디어, 보고서 초안 |
| **행정업무 도우미** | 회의록, 업무보고서, 행사 결과보고서, 공문, 교육 프로그램 운영보고서 초안 |
| **Excel 데이터 분석** | 기초 통계·빈 값 확인·항목별 집계·막대 그래프 — **숫자는 프로그램이 직접 계산**합니다. AI는 계산된 표를 해석해 보고서를 씁니다 |

결과는 **Word로 저장**, **텍스트로 저장**, **통계 결과를 Excel로 저장** 버튼으로 원하는 위치에 저장합니다.

### 꼭 알아 두실 점
- AI가 만든 결과는 **초안**입니다. 사용 전에 반드시 확인해 주세요.
- AI는 자료에 없는 내용을 만들지 않도록 설정되어 있지만, 틀릴 수 있습니다. 특히 참고문헌·수치는 원문으로 확인해 주세요.
- 한글(HWP) 파일은 아직 지원하지 않습니다. **PDF로 저장**한 뒤 불러와 주세요. 스캔한 이미지 PDF는 글자를 읽지 못합니다.
- 학생 개인정보는 **소속 대학의 개인정보 보호 규정**에 따라 다뤄 주세요. 실명 대신 별칭 사용을 권합니다.

## 4. 개인정보 보호 설정
- **로컬 전용 확인됨**(초록색): 실행 중인 AI 엔진을 직접 검사해 ① 클라우드 기능 꺼짐 ② 외부에서 접속 불가 ③ 선택한 AI가 이 컴퓨터에 있음을 모두 확인한 상태입니다. 하나라도 확인되지 않으면 회색으로 표시됩니다.
- **대화 기록 저장**: 기본은 꺼짐. 켜면 대화가 암호화되어 저장됩니다.
- **인터넷 사용 허용**: 끄면 앱은 인터넷을 전혀 사용하지 않습니다(이미 받은 AI는 계속 사용 가능).
- **인터넷 사용 기록**: 앱이 인터넷 사용을 허용·차단한 내역(내려받은 항목 이름만)을 볼 수 있습니다.
- **자료 삭제**: 저장된 대화, 상담 기록을 완전히 지웁니다.
- 컴퓨터 전체 백업이나 클라우드 동기화(OneDrive, iCloud 등)를 쓰시면 암호화된 자료 파일이 함께 복제될 수 있습니다. 교수님이 저장한 Word·Excel 결과 파일은 암호화되지 않습니다.

## 4-1. 학생 개인정보를 넣기 전에 — 보안 설정 (꼭 해 주세요)
1. **앱 잠금 암호 설정**: *개인정보 보호 설정 → 앱 잠금 → 잠금 암호 설정하기*. 6자 이상, 다른 곳에서 쓰지 않는 문장형 암호를 권합니다.
   - 암호를 잊으면 저장된 기록을 **되찾을 수 없습니다**. 암호는 어디에도 보관되지 않습니다.
   - 암호를 잊었다면 잠금 화면의 *암호를 잊으셨나요? → 전체 초기화*만 가능합니다(기록 삭제, AI 모델은 유지).
2. **자동 잠금**: 기본 10분. 자리를 비울 때는 왼쪽 아래 *지금 잠그기*를 누르세요.
3. **화면 공유·캡처 주의**: 화상회의로 화면을 공유하거나 캡처할 때는 상담 기록이 보이는 화면을 닫아 주세요.
4. **학생 기록 가명 처리**: 기본 켜짐. AI 결과물에 실명·번호가 남지 않습니다. 대응표는 화면에만 보입니다.
5. **컴퓨터 디스크 암호화**: Windows *설정 → 개인 정보 및 보안 → 장치 암호화*(또는 BitLocker), Mac *시스템 설정 → 개인정보 보호 및 보안 → FileVault*. 저장한 Word·Excel 결과 파일까지 보호됩니다.
6. *보안 점검*의 7개 항목이 모두 초록색인지 확인하세요.

### 교수님 보안 수칙
- 필요한 정보만 넣고, 주민등록번호·건강 정보 같은 민감정보는 넣지 않습니다.
- Word·Excel로 저장하거나 복사한 내용은 이 앱의 암호화 밖에 있습니다. 공유 폴더·메신저·메일로 보내기 전에 확인합니다.
- 화상회의 중에는 상담 기록 화면을 열지 않습니다.
- 다 쓴 기록은 바로 지우고, 컴퓨터를 반납·폐기할 때는 *전체 초기화*를 먼저 합니다.
- 업데이트는 *앱 업데이트* 메뉴나 공식 릴리스 페이지에서만 받습니다. 메일·메신저로 받은 설치 파일은 열지 않습니다.
- 학생 개인정보 처리는 소속 대학의 규정을 따릅니다.

## 4-2. 앱 업데이트
1. 왼쪽 메뉴 *앱 업데이트 → 업데이트 확인하기*. 처음 한 번 GitHub 접속 동의가 필요합니다(문서·기록은 전송되지 않음).
2. 새 버전이 있으면 달라진 점을 확인하고 *새 버전 내려받기*를 누릅니다. 공식 파일과 일치하는지 자동으로 확인합니다.
3. Windows: *설치 시작(앱이 닫힙니다)* → 설치 안내를 따릅니다. Mac: *설치 파일 열기* → 이 앱을 종료한 뒤 새 앱을 응용 프로그램 폴더로 끌어다 놓습니다.
4. 저장된 기록·설정·AI 모델은 그대로 남습니다.

## 5. 문제가 생겼을 때
| 증상 | 해결 방법 |
|---|---|
| "AI 실행 엔진에 연결할 수 없습니다" | *내 AI 모델 관리*에서 **엔진 다시 시작하기**. 계속되면 컴퓨터를 다시 시작 |
| "저장 공간이 부족합니다" | 필요한 용량만큼 공간을 비우거나 더 가벼운 AI 선택 |
| "메모리가 부족합니다" | 다른 프로그램을 닫거나 *빠르고 가벼운 AI*로 바꾸기 |
| 내려받기가 멈춤 | 인터넷 연결 확인 후 **다시 시도** (받은 부분부터 이어 받음) |
| 답변이 너무 느림 | 더 가벼운 AI로 바꾸기 |
| 보안 프로그램이 실행을 막음 | 기관 IT 부서에 `ollama` 실행 파일 허용을 요청 |
| 잠금 암호를 여러 번 틀렸다고 나옴 | 표시된 시간만큼 기다린 뒤 다시 입력 (3번 틀린 뒤부터 대기 시간이 늘어남) |
| (v0.2.0) 캡처하거나 화면 공유하면 앱 창이 사라짐 | v0.2.0의 ‘화면 캡처 방지’ 기능 때문입니다. *개인정보 보호 설정 → 화면 보호*에서 끄면 바로 캡처됩니다. 다음 버전에서는 이 기능이 빠집니다 |
| 업데이트 확인이 안 됨 | 인터넷 연결 확인. 잠시 뒤 다시 시도(GitHub 요청 한도). 또는 공식 릴리스 페이지에서 직접 받기 |

## 6. 제거하기
### Windows
*설정 → 앱 → 설치된 앱*에서 **Philosophy Local AI** → *제거*.
프로그램 제거 후에도 AI 모델과 자료 폴더는 남습니다. 완전히 지우려면 아래 폴더도 삭제하세요:
- `%LOCALAPPDATA%\kr.philosophy-ai.local-ai` (AI 엔진, AI 모델, 암호화된 자료)
- 암호화 키: *자격 증명 관리자 → Windows 자격 증명*에서 `kr.philosophy-ai.local-ai` 항목 삭제

### macOS
1. 응용 프로그램 폴더에서 앱을 휴지통으로 옮깁니다.
2. 자료까지 지우려면 Finder에서 *이동 → 폴더로 이동*에 `~/Library/Application Support/kr.philosophy-ai.local-ai` 입력 후 폴더 삭제.
3. 암호화 키: *키체인 접근*에서 `kr.philosophy-ai.local-ai` 항목 삭제.

> 제거 전에 앱의 *개인정보 보호 설정 → 자료 삭제*를 먼저 실행하시면 더 확실합니다.
