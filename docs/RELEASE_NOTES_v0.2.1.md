# 필로소피 로컬 AI v0.2.1 (시험판)

> **AI로 성장하고, 그 성장을 나눈다.**

## 달라진 점
- **화면 캡처 방지 기능을 뺐습니다.** v0.2.0에서는 화면을 캡처하거나 화상회의로 공유하면 이 앱 창이 사라져 보였습니다. 업무상 앱 화면을 캡처해야 한다는 의견에 따라 이 기능을 없앴습니다. 이제 앱 화면을 평소처럼 캡처·공유할 수 있습니다.
- 대신 **화면을 공유하거나 캡처할 때는 상담 기록이 보이는 화면을 닫아 주세요.** 캡처한 이미지에 학생 정보가 담기지 않았는지 꼭 확인해 주세요. (교수님 보안 수칙에 반영)
- 보안 점검 항목이 6개로 바뀌었습니다.
- **이미 받은 AI를 다시 받으라고 묻던 문제를 고쳤습니다.**
  - 처음 설정 화면과 AI 내려받기 화면에서, 이 컴퓨터에 이미 있는 AI는 ‘설치됨’으로 표시하고 내려받기 대신 **‘이 AI 사용하기’** 버튼을 보여 줍니다.
  - 실행 엔진이 없는 재설치 상황에서도 앱 모델 폴더에 남은 완전한 모델을 찾습니다. 모델은 다시 받지 않고 필요한 실행 엔진만 설치합니다.
  - 기존 모델 확인이 끝나기 전에는 다운로드를 시작하지 않습니다.
  - 받은 AI가 있는데 사용할 AI가 선택되어 있지 않으면 자동으로 선택합니다.
  - AI 실행 엔진이 잠시 멈춘 경우 ‘AI 모델 준비하기’ 대신 **‘AI 엔진 다시 시작’** 버튼을 보여 줍니다 (다시 내려받을 필요 없음).
  - 보안 저장소의 열쇠를 찾지 못한 경우에도 선택한 AI·처음 설정 완료 같은 설정은 남겨 둡니다.
  - 참고: 이 앱은 보안을 위해 AI 모델을 앱 전용 폴더에 따로 보관합니다. **Ollama 프로그램 등 다른 앱으로 받은 모델은 이 앱에서 보이지 않아** 한 번 더 받아야 합니다.

## 업데이트 방법
- v0.2.0을 쓰고 계시면 왼쪽 메뉴 **‘앱 업데이트’ → 업데이트 확인하기**에서 바로 받을 수 있습니다.
- 저장된 대화·상담 기록·설정·잠금 암호와 AI 모델은 그대로 남습니다.

## ⚠️ 시험판입니다
- 실제 AI 모델로 하는 검증과 Windows·Mac 실제 컴퓨터 시험이 아직 끝나지 않았습니다.
- 코드 서명이 없어 설치할 때 경고가 나옵니다. Windows: ‘추가 정보 → 실행’, Mac: ‘시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기’
