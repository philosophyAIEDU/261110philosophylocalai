# 필로소피 로컬 AI v0.2.6 (시험판)

> **AI로 성장하고, 그 성장을 나눈다.**

## ollama.com의 다른 AI를 직접 추가할 수 있습니다
추천 목록에 없는 AI도, **ollama.com 공식 모델 목록**(ollama.com/library)에 있으면 이름으로 추가해 이 컴퓨터에서 쓸 수 있습니다.

- **사용법**: ‘내 AI 모델 관리’ → ‘ollama.com의 다른 AI 직접 추가하기’에 `qwen3:8b`, `exaone3.5:7.8b`처럼 **이름:크기**를 넣고 ‘추가’ → ‘내려받기’.
  ollama.com 페이지의 `ollama run 모델이름`을 그대로 붙여 넣어도 됩니다.
- **이름을 몰라도 됩니다 — 목록에서 고르기**: ollama.com에서 많이 쓰는 AI 34개(EXAONE, Llama, DeepSeek-R1, Phi-4, Mistral, gpt-oss 등)를
  설명·용량·만든 곳·라이선스와 함께 보여 주고, **이 컴퓨터에서 여유 있게/빠듯하게 실행되는지** 표시합니다.
  ‘한국어’, ‘가벼움’, ‘추론’, ‘코딩’ 등으로 골라 보고 **‘추가하고 내려받기’** 한 번으로 받을 수 있습니다.
  이 목록은 앱에 들어 있어 인터넷을 쓰지 않으며, 앱을 업데이트할 때 새 모델이 추가됩니다.
- 내려받은 뒤에는 추천 AI와 똑같이 **이 컴퓨터 안에서만** 실행됩니다. 대화·문서는 밖으로 나가지 않습니다.

## 안전장치
- **ollama.com 공식 목록의 모델만** 추가할 수 있습니다. 다른 사이트의 모델, 다른 사람이 올린 모델(`이름/모델`), **클라우드(원격) 모델**은 막혀 있습니다.
- 내려받은 모델이 원격 모델로 확인되면 바로 지우고 알려 드립니다.
- 직접 추가한 모델도 ‘개인정보 보호 설정’의 인터넷 사용 기록에 남습니다.

## 꼭 확인해 주세요
- **컴퓨터 성능**: 목록의 ‘실행’ 표시는 예상치이며, 이름으로 직접 넣은 모델은 앱이 미리 확인하지 못합니다. 모델 파일 크기가 컴퓨터 메모리의 절반을 넘으면 매우 느리거나 실행되지 않을 수 있습니다.
- **라이선스**: 모델마다 사용 조건이 다릅니다. 특히 **‘비상업’** 표시 모델(EXAONE, Aya 등)은 사용 범위가 제한되니 ollama.com 모델 페이지에서 확인해 주세요.
- **목록의 용량은 근사치**입니다. 실제 크기는 내려받기를 시작하면 표시됩니다.
- **품질**: 추천 목록의 AI와 달리 한국어 실력·답변 품질은 개발팀이 확인하지 않았습니다.

## 업데이트 방법
‘앱 업데이트’ 메뉴에서 ‘시험판(베타) 버전도 받기’를 켠 상태로 업데이트를 확인하세요. 기존 기록·설정·잠금 암호·AI 모델은 그대로 남습니다.

코드 서명·공증이 없는 시험판입니다. 이번 기능은 가짜 엔진과 화면 미리보기로 시험했으며, 실제 ollama.com 모델 내려받기는 Windows·Mac에서 아직 확인하지 않았습니다.
