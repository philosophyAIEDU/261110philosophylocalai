# 필로소피 로컬 AI v0.1.0-beta.1 (시험판)

> **AI로 성장하고, 그 성장을 나눈다.**
> 교수님의 컴퓨터 안에서만 실행되는 로컬 AI 프로그램의 첫 시험판입니다.

## ⚠️ 먼저 읽어 주세요 — 시험판입니다
- **실제 AI 모델로 하는 검증이 아직 끝나지 않았습니다.** 개발 환경에서 모델 저장소 접속이 막혀,
  오프라인 채팅·PDF 분석·프롬프트 인젝션 검사를 실제 모델로는 확인하지 못했습니다. (보안 검사 10개 중 7개 통과, 3개 부분 통과)
- **Windows·macOS 실제 컴퓨터에서 설치·실행 시험을 하지 않았습니다.** (각 운영체제에서 자동 테스트와 빌드는 통과)
- **코드 서명·공증이 없습니다.** 설치할 때 경고가 나옵니다.
  - Windows: "Windows의 PC 보호" → *추가 정보* → *실행*
  - macOS: *시스템 설정 → 개인정보 보호 및 보안* → *그래도 열기*
- **실제 학생 개인정보는 충분한 시험을 마친 뒤에 사용해 주세요.** 처음에는 가상 자료로 사용해 보시기를 권합니다.

## 내려받기
| 운영체제 | 파일 |
|---|---|
| Windows 10/11 (64비트) | `Philosophy.Local.AI_0.1.0_x64-setup.exe` |
| macOS 12 이상 (Apple 칩·Intel 공용) | `Philosophy.Local.AI_0.1.0_universal.dmg` |

설치 후 첫 실행에서 AI 실행 엔진(Ollama 0.40.16, 공식 배포 파일·SHA-256 확인)과 AI 모델을 내려받습니다.
여유 공간 10GB 이상, 메모리 8GB 이상을 권장합니다.

## 주요 기능
- 컴퓨터 사양 자동 진단과 AI 모델 2~3개 추천 (Qwen 3, Gemma 3)
- 버튼 한 번으로 AI 실행 엔진·모델 설치, 무결성 확인, 실행 테스트
- AI 대화, 강의자료 분석, 학생 지도, 연구자료 분석, 행정 문서 초안, Excel·CSV 통계(코드로 정확히 계산)
- Word·Excel·텍스트로 결과 저장
- 로컬 전용 실행을 실제로 검사해 표시, 암호화 저장, 대화 저장 기본 꺼짐, 인터넷 사용 기록

## 검증된 것
- 실제 Ollama 0.40.16: 공식 파일 무결성, 클라우드 기능 꺼짐, 127.0.0.1 전용 실행, 외부 접속 차단, 종료 시 정리 (Linux)
- 인터넷을 끊은 상태에서 앱 기능 테스트 전체 통과, 테스트 중 외부 연결 시도 없음 (Linux)
- 앱 강제 종료 시 AI 엔진 정리 (Linux)
- Windows·macOS에서 핵심 자동 테스트 통과 및 설치 파일 빌드
