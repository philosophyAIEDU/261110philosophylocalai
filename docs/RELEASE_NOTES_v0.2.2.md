# 필로소피 로컬 AI v0.2.2 (시험판)

## 엔진 시작과 복구 안내 개선
- ‘로컬 전용 미확인’ 화면과 ‘내 AI 모델 관리’에서 엔진 복구 버튼을 제공합니다.
- 엔진이 설치되어 있으면 ‘AI 엔진 다시 시작하기’, 설치되어 있지 않으면 ‘실행 엔진만 설치하고 시작하기’를 표시합니다. 엔진 설치에는 인터넷 사용 동의가 필요합니다.
- 엔진 복구는 AI 모델을 다시 내려받거나 기존 모델을 삭제하지 않습니다.
- 엔진 자동 시작 실패 시 실제 오류를 표시합니다. 일반적인 ‘AI 모델을 준비하세요’ 문구로 원인을 숨기지 않습니다.
- 종료된 엔진 프로세스를 실행 중으로 표시하지 않도록 수정했습니다.
- 로컬 전용 표시는 실행 중인 엔진의 검사에 통과한 경우에만 표시합니다.

## 업데이트
앱의 ‘앱 업데이트’에서 ‘시험판 포함’을 켜고 업데이트를 확인하거나, 웹사이트에서 v0.2.2 설치 파일을 내려받아 설치하세요. 기존 앱 자료 폴더와 모델 폴더를 유지해 주세요.

## 확인 범위
엔진 종료·재시작 자동 테스트와 시작 실패·엔진 누락 복구 화면을 검증했습니다. 각 사용자 컴퓨터에서 엔진이 시작되지 않는 원인은 표시되는 오류를 통해 별도로 확인해야 합니다.

코드 서명·공증이 없는 시험판이며 Windows·Mac 실제 컴퓨터의 설치·실행 확인은 별도로 필요합니다.
