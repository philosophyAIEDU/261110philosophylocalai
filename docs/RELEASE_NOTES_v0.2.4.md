# 필로소피 로컬 AI v0.2.4 (시험판)

> **AI로 성장하고, 그 성장을 나눈다.**

## 이미 받은 AI를 다시 받으라고 묻던 문제 수정
앱을 다시 설치한 뒤, 예전에 이 앱으로 받아 둔 AI 모델이 컴퓨터에 그대로 있는데도 다시 내려받으라고 안내하는 문제가 있었습니다.

- **원인**: AI 실행 엔진(Ollama 0.40)은 받은 모델을 새로운 폴더 구조(`manifests-v2`)에 저장하는데, 이전 버전의 “이미 받은 AI 확인”은 옛 폴더 구조만 살펴봐서 찾지 못했습니다.
- **수정**: 엔진이 실제로 쓰는 새 구조와 옛 구조를 모두 확인합니다. 여러 형식을 묶은 모델(매니페스트 목록)도 확인합니다.
- **확인 방법**: 모델 파일의 모든 조각이 기록된 크기대로 온전히 있을 때만 “이미 있음”으로 봅니다. 덜 받은 모델은 이어서 받습니다.
- AI 실행 엔진이 설치되어 있지 않거나 잠시 시작하지 못해도, 앱 모델 폴더를 직접 살펴 이미 받은 AI를 찾습니다.
- 찾으면 처음 설정 화면과 ‘내 AI 모델 관리’에서 **‘설치됨’**으로 표시하고, 모델은 다시 내려받지 않습니다. (엔진이 없으면 엔진만 설치합니다)

## 검증
- 실제 AI 실행 엔진(Ollama 0.40.16)으로, 새 구조로 저장된 모델을 엔진과 앱이 똑같이 찾는지 확인했습니다.
- 링크가 앱 모델 폴더 밖을 가리키거나, 덜 받았거나, 클라우드(원격) 모델인 경우는 “있음”으로 보지 않습니다.

## 알아 두실 점
- 이 앱은 보안을 위해 AI 모델을 **앱 전용 폴더**에 따로 보관합니다. Ollama 프로그램 등 **다른 앱으로 받은 모델은 이 앱에서 보이지 않습니다.**
- 앱을 지울 때 “앱 데이터도 삭제”를 선택하셨다면 모델 파일도 함께 지워져, 다시 받아야 합니다.

## 업데이트 방법
‘앱 업데이트’ 메뉴에서 ‘시험판(베타) 버전도 받기’를 켠 상태로 업데이트를 확인하세요. 저장된 기록·설정·잠금 암호와 AI 모델은 그대로 남습니다.

코드 서명·공증이 없는 시험판입니다.
