# 필로소피 로컬 AI v0.2.0 (시험판) — 보안 강화와 앱 내 업데이트

> **AI로 성장하고, 그 성장을 나눈다.**

## 새로운 보안 기능
- **앱 잠금 암호** — 저장된 대화·상담 기록을 여는 열쇠를 교수님만 아는 암호로 한 번 더 잠급니다. 암호 없이는 이 컴퓨터에 로그인한 사람도 기록을 볼 수 없습니다.
- **자동 잠금** — 정해진 시간(기본 10분) 동안 사용하지 않으면 자동으로 잠기고, 열려 있던 문서도 메모리에서 지웁니다. 왼쪽 아래 ‘지금 잠그기’로 바로 잠글 수도 있습니다.
- **화면 캡처·화면 공유 방지** — Zoom·Teams 화면 공유와 캡처에 이 앱 창이 검게 나옵니다. (Windows·Mac, 기본 켜짐)
- **학생 기록 가명 처리** — AI에 보내기 전에 학생 이름을 ‘학생1, 학생2…’로 바꾸고 전화번호·이메일·학번·주민번호를 가립니다.
- **보안 점검** — 잠금, 자동 잠금, 디스크 암호화(BitLocker/FileVault) 등 7가지를 한눈에 확인합니다.
- **전체 초기화** — 암호화 열쇠를 파기해, 컴퓨터 백업에 남은 이전 사본까지 읽을 수 없게 합니다.
- **교수님 보안 수칙** — 화면 곳곳에 지켜야 할 유의사항을 안내합니다.

## 보안 점검에서 고친 점
- 앱 화면이 파일 경로를 직접 지정하던 구조를 없앴습니다. 이제 파일 열기·저장은 항상 운영체제 창에서 교수님이 고른 파일만 사용합니다.
- 전화번호·학번 뒤에 ‘로’, ‘이고’ 같은 조사가 붙으면 가려지지 않던 문제를 고쳤습니다.
- 매우 큰 Excel·CSV 파일로 앱이 멈추지 않도록 크기 상한(100MB)을 두었습니다.
- 정리 작업 중 임시 파일이 디스크에 남지 않도록 했습니다.

## 앱 안에서 업데이트하기
- 새 메뉴 **‘앱 업데이트’**에서 버튼을 누르면 새 버전을 확인하고, 릴리스 노트를 보여 주고, 설치 파일을 내려받습니다.
- 공식 저장소의 파일만 받으며, GitHub에 기록된 SHA-256 값과 다르면 자동으로 삭제합니다.
- 자동으로 확인하지 않습니다. 교수님이 누를 때만 GitHub에 접속하며, 문서·대화·기록은 전송되지 않습니다.
- v0.1.0을 쓰고 계신다면 이번 한 번은 아래 파일을 직접 설치해 주세요. 다음 버전부터는 앱 안에서 업데이트할 수 있습니다. 기존 기록과 AI 모델은 그대로 남습니다.

## ⚠️ 시험판입니다
- 실제 AI 모델로 하는 검증과 Windows·Mac 실제 컴퓨터 시험이 아직 끝나지 않았습니다. (앱 잠금·자동 잠금·파일 선택 창은 Linux에서 실제 앱으로 확인)
- 코드 서명이 없어 설치할 때 경고가 나옵니다. Windows: ‘추가 정보 → 실행’, Mac: ‘시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기’
- **학생 개인정보를 넣기 전에 ‘개인정보 보호 설정 → 보안 점검’을 모두 초록색으로 만들어 주세요.**
